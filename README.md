# Bulk Website Speed Auditor & Cold Outreach Engine (PRO v2.1)

A high-performance SaaS engine built for freelancers and agencies to bulk audit website speeds, identify slow client sites (<50 score), and generate personalized data-backed cold outreach pitches ready for Mailmeteor and cold email campaigns.

## 🚀 Features
- **100% Genuine Google PageSpeed Insights (Lighthouse 13.4.1)**: Dual Mobile & Desktop audits side-by-side.
- **SERP Keyword Lead Finder**: Live search scraper for organic business leads (excludes Yelp/directories).
- **Business Categories**: SaaS, Ecommerce, Local Business, Agency, and General.
- **Cold Email Pitch Engine**: 4 proven outreach frameworks + Mailmeteor merge tags.
- **Rate-Limiting Control**: Configurable inter-request pause gaps (1s to 5s) for smooth batch audits.
- **Zero Data Loss**: Local browser persistence + JSON project export/restore.

## 🛠️ Local Development

```bash
npm install
npm run dev
```
